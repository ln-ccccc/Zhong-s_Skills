# 数据计算与可视化验收

在计算、推理、统计、图表或汇报样例的验收中使用。纯公式单测可使用合成数据；结论覆盖真实业务时，另需有来源可核查、形态符合业务的样例。无法取得真实数据就记录该部分未验证，继续已有授权范围内的检查。

## 三项结论与证据

| 验收项 | 要证明什么 | 最小证据 |
|---|---|---|
| 功能运行 | 用户入口到计算、保存、历史、下载按契约完成 | 实际请求/响应、步骤记录、错误状态；只覆盖本次操作范围 |
| 数据可信 | 输入具有所需信息，结果符合业务语义 | 来源与元数据、独立参考数值、有效数据范围与身份核对 |
| 显示正确 | 用户看到和下载的是对应数据，表达没有误导 | 连续浏览器操作、截图、悬停读数、实际导出内容核对 |

每项标记通过、失败、未验证或不适用。图表存在时，“API通过”不能替代显示验收；输出存在时，“下载成功”不能替代内容核对。缺少参考真值时，不得把结果合理性检查称为准确率验证。

## 1. 先检查输入是否有证明力

- 记录样例的来源、观测日期、版本/摘要、单位、字段含义，以及实体ID或空间范围。核对实际加载字节与来源记录，不能只信文件名、页面标题和`synthetic=false`标签。
- 明确哪些值来自观测，哪些经过重采样、辐射校正、归一化或人工构造；记录处理参数。按对应元数据确定缩放、偏移及分辨率，不能按外观或年份猜测。
- 样例应覆盖当前要展示的业务差异。例如展示不同地物时选择包含不同地物的真实多波段影像；不要把合法均匀样例强行加工出变化。
- 合成样例用于已知公式、边界和异常回归，不能作为真实观测证明。真实RGB影像没有NIR/SWIR时，不得通过复制通道或固定比例伪造真实红外波段。

## 2. 独立复算与合理性检查

- 参考值来自独立公式、可信标准样例或独立测量，不能调用待测函数生成预期值，也不能照抄API结果。用可手算小样例锁定公式，再用真实复杂样例核对业务表现。
- 追查单位、字段/波段顺序、缩放偏移、时间对应、空间对齐和ROI。统计明确属于整幅、选区还是单一实体，核对有效数量与分母。
- 按输入元数据和契约构造有效掩膜；NoData、NaN、Inf、零分母是否参与计算、拉伸、统计必须明确。合法的零值/负值不能未经依据当作无效值。检查全无效输入的约定行为，避免保存虚假有效结果。
- 检查有效数值的范围、均值、分位数、标准差或类别比例，并核对有依据的分组/空间差异。差异检查是合理性证据，不是独立真值。
- 在预期应有差异的样例中，恒定、接近恒定或多个结果异常相似时，检查固定通道比例、重复加载同一文件、默认值、缓存与掩膜错误。不要仅换色后验收，也不要为所有领域设置统一方差阈值。
- 例如NIR=3R、SWIR=2R时，非零分母像元的NDVI=(NIR−R)/(NIR+R)=0.5、NDBI=(SWIR−NIR)/(SWIR+NIR)=−0.2。公式正确，数据仍不足以证明真实地物差异。
- 两期预测之间的矩阵表示类别转移/一致性；精度混淆矩阵要有对应期的独立参考真值。不能把转移矩阵对角线比例当作准确率。

## 3. 从用户界面核对到真实产物

按实际业务路径执行“选择输入/年份/对象 → 计算 → 查看原图与结果 → 放大/悬停 → 切换 → 查看历史 → 下载”。记录用到的数据身份，核对图例、单位、时间、选区、悬停值与独立参考的一致性。

- 原图的RGB顺序、显示拉伸和分析结果分开核验；科学数值不应因显示拉伸而变化。既定原值显示契约须做像素核对。
- NoData的alpha、遮罩背景、结果颜色和有效零值必须可区分。实际放大原图并检查透明区域是否透出下层成果；需要时换底色或隐藏下层取证。
- PNG逐像素比较须先核对尺寸，并使用新画布或`clearRect`清空画布后绘参考图；比较RGBA及有效掩膜，避免透明区域留下旧图而产生假绿。仅比较RGB或只看缩略图可能漏错。
- 图表逐项核对悬停数值、轴范围、图例、单位和筛选状态；连续快速切换后核对最后选择与显示，检查旧请求覆盖新状态。含动效时检查过渡、卡顿和已有减少动态效果设置；没有测量FPS就不声称性能指标通过。
- 解析浏览器实际下载的CSV/图片/报告，核对年份、实体、行列、单位、数值、中文编码与图例。API直读可作独立参考，不能替代用户下载链路。

## 4. 验收结论绑定测试对象

记录源码版本或工作区摘要、前端资产/镜像/交付包摘要、输入摘要、配置、测试范围、运行编号及证据路径。改动代码、数据或构建产物后，对受影响路径验证最终产物；旧通过记录保留为历史，不替代本次验收。

超时、502或其他失败先保留证据，再区分产品、环境和自动化工具问题。未归因时报告未验证/失败，不能猜测为工具故障后忽略。重试通过须同时说明失败记录与是否解决原因，不能据一次成功宣称稳定。

停止“可用于真实展示/全部功能通过”这类声明的条件：关键输入无来源、数值与独立参考不符、图表/下载绑定错误，或所声称范围没有最终产物的通过记录。可以交付已验证部分和清晰限制，不能扩大证明范围。
