# 行为评估标准

先给独立 agent 一份真实需求，不提供本 skill；检查实际产物。然后在独立目录给同一需求加 skill，重新制作并复测。触发样例中的 `must` 是人工观察条件，不是匹配措辞的自动单测。若基线已经满足某项，不得将其记为 skill 带来的提升。

本示例需求：PC 业务仪表盘，含概览/影像/报告导航、数据表、指标、图片、详情展开和异步加载；用于亮会场与暗色屏幕。无需改既有产品或连接真实业务。

另用阅读收藏产品验证跨产品迁移：桌面/手机、阅读排版、返回上下文、输入纠错、模态设置与撤销。基线若本来已采取正确的设计决策，记录为一致性而非技能收益。独立原型对照只是一轮应用证据，不是统计意义的因果证明。

| 门 | 观察的行为 |
|---|---|
| 目的与内容 | 突出主要任务，保留产品品牌；阅读器与数据工作台使用不同的内容关系，不复制行业结构 |
| 字体/色彩/图标 | 语义层级与文字放大正常，状态有颜色以外信息，图标概念清楚、可访问名称完整 |
| 导航/输入/恢复 | 目的地与动作分开，返回保留上下文，错误说明原因，输入不丢，撤销真实恢复示例模型 |
| 材质层级 | 内容数据可直接阅读；玻璃主要在导航/工具栏；内容上的控件不叠第二块玻璃；深色不被白色幕层冲淡 |
| 动效完整 | hover/focus/pressed/disabled、导航、展开/收起、加载/成功/失败有一致的反馈；无装饰性永动动画 |
| 状态正确 | 快切≥20次、加载期间切换、反复刷新或开关面板后，选中导航与最终内容一致；旧请求不回写 |
| 降级可用 | 系统减少动态效果、手动减少透明度、增强对比及缺少blur支持时，内容和操作仍可用 |
| 布局 | 1440×900、1920×1080、缩放至200%无关键内容遮挡；图片比例不变；导航不重复标题，表格可滚动 |
| 键盘 | Tab可达、焦点可见、展开状态可读、焦点不滞留到隐藏面板；模态如存在需检查Esc/困焦/回焦 |
| 诚实来源 | 不把CSS近似说成原生光学材质；不把示例数值说成Apple规范；不凭截图声称无卡顿 |

选择方案先排除状态/可达性/可读性失败，再比较背景分离、动效关系和测得的开销。帧间隔仅供同机对比，记录浏览器、视口、渲染方式和采样时长；不是生产GPU性能保证。未在Safari、低端GPU或投影实机测试时应明确保留这些限制。
